## ⚡ Project Overview: Smart Power Monitor (C++)

This is a **learning-level project** written in **C++**. It combines basic physics with programming to show how we can track and manage electricity usage. The program calculates how much power a device uses and saves that data for later.

### ✨ What This Project Does

* **User Input:** It asks for the Voltage, Current, and how long the device was running.
* **Calculations:** It automatically figures out the Power (Watts) and total Energy (Watt-hours).
* **Smart Alerts:** The program checks the numbers and tells you if the power consumption is "Normal" or "High."
* **Data Saving:** It uses **File Handling** to save all measurements into a permanent text file so you don't lose them.
